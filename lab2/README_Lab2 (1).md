## Тема

Кросс-модальная классификация видеороликов датасета HowTo100M с использованием мультимодального pipeline и нейросетевой модели на PyTorch.

Цель лабораторной работы — реализовать полный учебный pipeline классификации видео: загрузить данные HowTo100M, подготовить признаки из разных модальностей, объединить их в общее представление и обучить модель, которая определяет тематическую категорию видеоролика.

В рамках работы решалась задача классификации видеороликов по категориям верхнего уровня из поля `category_1` датасета HowTo100M. В текущем запуске использовались первые 1000 записей после объединения основного CSV-файла с таблицей описаний задач.

8. Построить нейросетевую cross-modal модель для объединения трех модальностей.

## Теоретическая база

### Датасет HowTo100M

HowTo100M — это крупный датасет обучающих видеороликов с YouTube. Он используется в задачах video understanding, video classification и обучения видео-текстовых представлений. В лабораторной работе полный датасет не обрабатывался напрямую. Вместо этого использовалась metadata, содержащая сведения о видеороликах, их категориях и идентификаторах задач.

В коде загружаются два файла:

| Файл | Назначение | Количество записей в запуске |
| --- | --- | ---: |
| `HowTo100M_v1.csv` | основная таблица metadata | 1 238 911 |
| `task_ids.csv` | таблица с описаниями задач | 123 520 |

После загрузки файлы объединяются по `task_id`, а отсутствующие описания задач заменяются пустой строкой.

### Мультимодальный подход

Мультимодальный подход означает, что модель использует не один источник информации, а несколько. В данной работе используются три модальности:

| Модальность | Что используется в работе | Размерность признаков |
| --- | --- | ---: |
| Текст | `task_description` + `category_2` | 256 |
| Видео | визуальный embedding-вектор | 512 |
| Аудио | аудио embedding-вектор | 768 |

Текстовые признаки извлекаются с помощью `TfidfVectorizer`. Этот метод превращает текст в числовой вектор, где учитывается важность слов в документах. Максимальное число текстовых признаков ограничено значением `max_features=256`.

Визуальные и аудиопризнаки в текущем учебном решении представлены синтетическими embedding-векторами фиксированной размерности. Это позволяет проверить архитектуру pipeline и процесс объединения модальностей без скачивания и тяжелой обработки самих видеороликов.

### Объединение модальностей

Каждая модальность сначала проходит через свой линейный слой-проекцию:

```text
text  -> Linear(text_dim, hidden_dim)
video -> Linear(video_dim, hidden_dim)
audio -> Linear(audio_dim, hidden_dim)
```

После этого признаки объединяются через конкатенацию:

```text
fused = concat(text_projection, video_projection, audio_projection)
```

Итоговый объединенный вектор передается в классификатор, который выдает вероятности принадлежности объекта к каждому классу.

### Cross-modal нейросетевая модель

В работе реализована модель `RealisticCrossModalModel`. Она состоит из трех частей:

1. Отдельные проекции для текста, видео и аудио.
2. Объединение признаков через `torch.cat`.
3. Полносвязный классификатор с `BatchNorm1d`, `ReLU` и `Dropout`.

Упрощенно архитектуру можно представить так:

```text
Text features  -> Linear -> ReLU ┐
Video features -> Linear -> ReLU ├-> Concatenation -> Classifier -> Class
Audio features -> Linear -> ReLU ┘
```

В модели используется скрытая размерность `hidden_dim=128`. После проекции каждая модальность имеет размерность 128, поэтому после объединения получается вектор размерности 384.

### Dropout и BatchNorm

`Dropout` используется для регуляризации. Во время обучения он случайно отключает часть нейронов, чтобы модель не слишком сильно запоминала обучающую выборку.

`BatchNorm1d` нормализует значения внутри батча и помогает стабилизировать обучение. Это особенно полезно в полносвязных сетях, где признаки могут иметь разный масштаб.

### Confusion matrix

Confusion matrix показывает, какие классы модель определяет правильно, а какие путает между собой. По строкам указываются истинные классы, по столбцам — предсказанные классы. Диагональные значения показывают верные предсказания, а остальные ячейки — ошибки.

## Архитектура модели

В работе использовалась нейросетевая модель на PyTorch.

Основные параметры модели:

| Параметр | Значение |
| --- | ---: |
| `text_dim` | 256 |


| Scheduler | `ReduceLROnPlateau` |
| Batch size | `32` |
| Максимальное число эпох | `15` |
| Early stopping | есть, patience = 5 |

#### `Home and Garden`

## Анализ результатов

Полученные результаты показывают, что реализованный cross-modal pipeline успешно решает задачу классификации видеороликов на выбранной подвыборке HowTo100M. Модель использует три типа признаков: текстовые, визуальные и аудио. После проекции признаки объединяются и передаются в полносвязный классификатор.

На тестовой выборке модель достигла accuracy **88.00%**, что является хорошим результатом для учебного эксперимента. При этом важно учитывать особенности текущей реализации: текстовые признаки извлекаются реально через TF-IDF, а визуальные и аудиопризнаки представлены синтетическими embedding-векторами. Поэтому результат в первую очередь демонстрирует корректность построения pipeline, архитектуры модели, процесса обучения и оценки качества.

Качество модели зависит от нескольких факторов:

1. **Дисбаланс классов.** В тестовой выборке некоторые классы представлены большим числом объектов, а некоторые — очень малым.
2. **Малое количество примеров для отдельных категорий.** Например, `Family Life` имеет только 3 объекта в test, поэтому даже одна ошибка сильно влияет на метрики.
3. **Смысловая близость категорий.** Домашние, образовательные, развлекательные и бытовые видео могут иметь похожие текстовые описания.
4. **Ограниченность признаков.** В текущем решении видео и аудио представлены синтетическими векторами, поэтому для полноценной практической классификации нужно заменить их реальными признаками из видео и аудио.
5. **Ограниченная подвыборка.** Использовались только первые 1000 записей, а не весь датасет.

Лучшие результаты были получены для классов `Hobbies and Crafts`, `Food and Entertaining`, `Cars & Other Vehicles` и `Home and Garden`. Наиболее сложными оказались `Education and Communications` и `Family Life`.

## Рекомендации по улучшению

Для дальнейшего развития работы можно предложить следующие улучшения:
