## ТЕОРЕТИЧЕСКАЯ БАЗА

### Классификация изображений

Классификация изображений - это задача компьютерного зрения, при которой модели необходимо отнести изображение к одному из заранее заданных классов. В данной лабораторной работе классами являются породы собак.

Так как в датасете Stanford Dogs представлено 120 пород, задача является многоклассовой. Для каждого изображения модель формирует вектор выходных значений, где каждый элемент соответствует одному классу. Итоговый класс выбирается по максимальному значению среди выходов модели.

### Датасет Stanford Dogs

В работе используется датасет Stanford Dogs. Он содержит изображения собак, распределенные по папкам, каждая из которых соответствует отдельной породе.

В загруженном наборе данных было обнаружено:

| ---------------------------- | --------------------- |
| Общее количество изображений | 20580                 |
| Количество классов           | 120                   |
| Размер обучающей выборки     | 14405                 |
| Размер валидационной выборки | 3087                  |
| Размер тестовой выборки      | 3088                  |
| Пример класса                | `n02085620-Chihuahua` |


Изображения загружаются из папки:

```text
/content/stanford_dogs/images/Images
```

Для удобной работы с данными был реализован класс `StanfordDogsDataset`, который автоматически ищет папку с изображениями, формирует список классов, сопоставляет каждому классу числовую метку и возвращает пару `image, label`.

### Предобработка и аугментация изображений

Перед подачей в нейронную сеть изображения приводятся к единому размеру:

```text
224 x 224
```

Для обучающей выборки используются следующие преобразования:

1. изменение размера изображения до 224x224;
2. случайное горизонтальное отражение;
3. случайное вертикальное отражение;
4. преобразование изображения в тензор;
5. нормализация по средним значениям и стандартным отклонениям ImageNet.

Для валидационной и тестовой выборок случайные аугментации не применяются. Используются только изменение размера, преобразование в тензор и нормализация. Это необходимо для того, чтобы оценка качества была стабильной и не зависела от случайных преобразований.

### Архитектура ResNeXt50

В качестве основной архитектуры используется модель:

```text
ResNeXt50_32x4d
```

ResNeXt является развитием идей ResNet. Она использует остаточные связи и групповые свертки, что позволяет модели эффективно извлекать признаки из изображений. В лабораторной работе применяется версия `resnext50_32x4d` из библиотеки `torchvision.models`.

Для решения задачи классификации 120 пород собак последний слой модели заменяется на новый полносвязный слой:

```python
model.fc = nn.Linear(model.fc.in_features, num_classes)
```

Это необходимо, так как исходная предобученная модель ImageNet рассчитана на другое количество классов.

### Transfer Learning и Fine-tuning

Transfer Learning - это подход, при котором используется модель, заранее обученная на большом датасете. В данной работе модель ResNeXt загружается с весами ImageNet, после чего дообучается на датасете Stanford Dogs.

Преимущество такого подхода заключается в том, что модель уже умеет выделять базовые визуальные признаки: контуры, текстуры, формы и части объектов. Поэтому для новой задачи ей нужно не учиться с нуля, а адаптировать уже имеющиеся признаки под конкретные классы.

В работе сравниваются два варианта fine-tuning:

1. предобученная ResNeXt50 + Adam;
2. предобученная ResNeXt50 + RAdam.

Отдельно проводится эксперимент с обучением ResNeXt50 с нуля, чтобы оценить влияние предобученных весов.

### Оптимизаторы Adam и RAdam

Adam - это популярный оптимизатор, который адаптивно изменяет скорость обучения для разных параметров модели. Он часто применяется при обучении нейронных сетей, так как хорошо работает на широком наборе задач.

RAdam - модификация Adam, которая добавляет механизм rectification. Он направлен на более стабильное поведение оптимизатора на ранних этапах обучения.

В лабораторной работе оба оптимизатора используются для дообучения предобученной модели. Для обучения с нуля используется Adam.

### Функция потерь CrossEntropyLoss

Для многоклассовой классификации применяется функция потерь:

```python
nn.CrossEntropyLoss()
```

Она сравнивает предсказания модели с правильными метками классов и показывает, насколько сильно модель ошибается. Чем меньше значение loss, тем лучше модель подбирает вероятности классов.

### Метрики оценки качества

Для оценки качества моделей используются Precision, Recall и F1-score с усреднением `macro`.

Precision показывает, какая доля объектов, отнесенных моделью к классам, была классифицирована правильно.

Recall показывает, какую долю объектов каждого класса модель смогла найти.

F1-score объединяет Precision и Recall в одну метрику. Эта метрика особенно важна при сравнении моделей, так как отражает общий баланс качества классификации.

В коде используется расчет метрик через функцию:

```python
precision_recall_fscore_support(..., average='macro')
```

Macro-усреднение означает, что метрики сначала считаются отдельно по каждому классу, а затем усредняются. Это важно для задачи с большим количеством пород, так как позволяет учитывать качество по всем классам, а не только по самым частым.

## АНАЛИЗ ОШИБОК И ОСОБЕННОСТЕЙ ОБУЧЕНИЯ

В работе сравнивались три подхода к обучению одной и той же архитектуры. Основное различие между ними заключается в наличии предобученных весов и выборе оптимизатора.

Первый важный результат - сильное преимущество transfer learning. Модели с предобученными весами уже после первой эпохи показывают заметно более высокое качество, чем модель, обучаемая с нуля. Это объясняется тем, что ResNeXt50, обученная на ImageNet, уже содержит полезные визуальные признаки.

Второй результат - преимущество RAdam над Adam в данной постановке эксперимента. Хотя Adam быстрее набирает качество на первой эпохе, RAdam к пятой эпохе показывает более высокий F1-score на валидации и на тестовой выборке.

Третий результат - низкое качество модели, обученной с нуля. Даже после 10 эпох F1-score остается значительно ниже, чем у предобученных моделей. Это связано с тем, что задача классификации 120 пород собак является сложной, а 10 эпох недостаточно для полноценного обучения глубокой сверточной сети с нуля.

### Возможные причины ошибок

Основные причины ошибок модели при классификации пород собак:

1. внешняя похожесть некоторых пород;
2. различия внутри одной породы по окрасу, размеру и позе;
3. наличие фона, который может отвлекать модель;
4. частично закрытые собаки на изображениях;
5. неравномерное качество фотографий;
6. недостаточное количество эпох при обучении с нуля;
7. возможное переобучение при fine-tuning, так как train F1 растет быстрее, чем validation F1.

### Анализ переобучения

В эксперименте с Adam Fine-tune к пятой эпохе Train F1 достиг 0.9360, а Val F1 составил 0.7781. Это говорит о том, что модель хорошо подстраивается под обучающую выборку, но качество на валидации растет медленнее.

В эксперименте с RAdam Train F1 к пятой эпохе составил 0.8992, а Val F1 - 0.8082. Разрыв между обучением и валидацией также есть, но итоговое качество на валидации выше, чем у Adam.

Для уменьшения переобучения можно использовать дополнительные методы регуляризации, более аккуратную стратегию аугментаций, scheduler для learning rate, early stopping и увеличение объема данных.
